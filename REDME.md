🚀 WEB API Billetera Virtual: 
Sistema de transferencia de dinero electrónico con el que se pueden hacer múltiples operaciones financieras.

🚀 Framework: Spring Boot.

🚀 Base de Datos: relacional Postgres
nombre de DB dmh en el archivo console.sql del proyecto esta la base con sus relaciones 
🔧 Lenguaje: Java 21.

🔧 Testing: Tests Unitarios.

⚙️ Servicios externos: Keycloak.

⚙️ Servicios externos: Eureka. para descubrir los servicios y para balanceo de cargas.
http://localhost:8761/ 

⚙️ Seguridad: Se utilizó JWT Token para seguridad.

🔧 Otros: JPA, Hibernate, Maven.

📋 Prueba API: Se utilizó Swagger para crear la documentacion de las apis. 
http://localhost:8500/swagger-ui/index.html#/User/getUser

⌨️ GIT: Se trabajaron ramas y se probaron Pull Requests.

📦 Deploy: Heroku (url: https://mibilleteravirtual.herokuapp.com). 
Se utilizó Postgre para base de datos, con la finalidad de consumir el servicio de manera gratuita.
